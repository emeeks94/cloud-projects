# ☁️ Cloud Projects

Hi there! 👋🏾 I'm Emeka (Hey-May-Car), and welcome to my little corner of the internet where my curiosity meets cloud infrastructure.

This repository is my personal cloud engineering playground. It is a growing collection of projects built on AWS (and eventually Azure) as I continue my journey toward becoming a well-rounded Cloud Engineer.

A little heads-up: Some projects will be simple. Some will be messy.

Some will probably break before they work. Be assured you will get a bit of both worlds.

---

## Why this repository exists

I realized something while learning cloud technologies:

It's easy to follow a tutorial.

It's much harder—and much more rewarding—to understand *why* an architecture is designed a certain way.

So instead of collecting certificates and half-finished labs, I decided to build real projects, document my thinking, and share the lessons along the way.

This repository will act as my journal to document the sweet, weird, and sully experiences in my cloud journey.

Every folder represents a problem I tried to solve, an architecture I designed, or a concept I wanted to understand better.

---

## What you'll find here

Each project typically includes:

- 🏗️ Architecture diagrams
- ☁️ Cloud infrastructure (AWS, Azure, GCP)
- 📸 Deployment screenshots
- 📝 Technical documentation
- ✍🏾 Blog articles explaining the design decisions (This will often take you to Medium, so brace up for some story about my boring life)

## My approach to learning

I learn by asking questions.

Lots of them.

You'll notice many of these projects aren't just "deploy this service."

Instead, they're experiments.

> What happens if I put the backend in a private subnet?

> Why should an Application Load Balancer be the only public entry point?

> How does CloudFront securely access a private S3 bucket?

Those questions usually lead to better architectures—and occasionally a few hours of troubleshooting.
